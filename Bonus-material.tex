\#\#Data Wrangling (dplyr)

Data wrangling is the process of preparing and transforming raw data
into a useful format. The \texttt{dplyr} package provides several
important functions:

\begin{itemize}
\tightlist
\item
  \texttt{select()} is used to choose specific columns\\
\item
  \texttt{filter()} extracts rows based on conditions\\
\item
  \texttt{mutate()} creates or modifies variables\\
\item
  \texttt{summarise()} calculates summary statistics\\
\item
  \texttt{group\_by()} groups the data before summarizing
\end{itemize}

It is important to always check column names and ensure variables have
the correct data types before performing operations.
